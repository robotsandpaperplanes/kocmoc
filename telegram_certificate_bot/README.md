# Telegram-бот сертификатов KOCMOC

Бот на Python 3.9+ и aiogram 3. Покупка пока работает в тестовом режиме:
кнопка `Оплатить N 🍅` не списывает деньги, а сразу создаёт сертификат в
SQLite.

## Что реализовано

- `/start` с приветствием «Я верю, что многие из вас...»;
- нижнее меню `🕰️ Который час?`, `⚓️ Плыть`, `🎁 Сертификат`,
  `📦 Мои сертификаты`;
- текущее время в UTC+0 и 24-часовом формате;
- результат «Вы плывете ✅» с вероятностью 99% и «Вы летите 🤣» с
  вероятностью 1%;
- покупка сертификата номиналом 5, 10, 15 или 20 🍅;
- необязательный комментарий;
- отображение комментария длиной максимум 1000 символов: 999 символов и `…`;
- случайный уникальный ID сертификата в формате `xxxx-xxxx`;
- список и карточки сертификатов пользователя;
- `/myid` для получения Telegram ID;
- `/admin` для разрешённых администраторов;
- поиск по ID, подтверждение и атомарное погашение;
- защита от повторного погашения;
- сохранение времени, Telegram ID и username администратора;
- автоматическая миграция базы из архивной MVP/V2.

## Настройка

Создайте файл `.env` из примера:

```bash
cp .env.example .env
```

Заполните:

```env
BOT_TOKEN=токен_из_BotFather
DATABASE_PATH=./data/bot.sqlite3
ADMIN_TELEGRAM_IDS=123456789
```

Для нескольких администраторов перечислите Telegram ID через запятую:

```env
ADMIN_TELEGRAM_IDS=123456789,987654321
```

Чтобы узнать ID, запустите бота и отправьте `/myid`. После изменения `.env`
перезапустите процесс. Команда `/admin` не показывает административные данные
пользователям, которых нет в `ADMIN_TELEGRAM_IDS`.

Файл `.env` исключён из Git. Не добавляйте в репозиторий токен бота.

## Запуск в GitHub Codespaces

Из корня репозитория:

```bash
cd telegram_certificate_bot
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env`, вставьте `BOT_TOKEN`, затем запустите:

```bash
python -m app.main
```

После запуска откройте бота в Telegram и отправьте:

```text
/start
```

Если виртуальное окружение и `.env` уже существуют:

```bash
cd telegram_certificate_bot
source .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

Остановка на компьютере: `Ctrl+C`. В мобильном Codespaces можно удалить
активный терминал кнопкой корзины и создать новый.

## Запуск через Docker

```bash
cd telegram_certificate_bot
cp .env.example .env
docker compose up --build
```

SQLite хранится в `telegram_certificate_bot/data/bot.sqlite3` и подключается к
контейнеру как volume.

## Тесты

```bash
cd telegram_certificate_bot
source .venv/bin/activate
python -m pytest -q
```

Тестами покрыты генерация ID, усечение комментария, обе вероятностные ветки,
создание сертификата, коллизия ID и запрет повторного погашения.

## Данные сертификата

Для каждого сертификата сохраняются:

- внутренний UUID и публичный ID `xxxx-xxxx`;
- Telegram ID и username покупателя;
- номинал и полный исходный комментарий;
- статус и время создания;
- время погашения;
- Telegram ID и username первого администратора, который его погасил.

Для совместимости сохраняются старые технические поля заказов и QR-токенов.
Существующая база обновляется при запуске без удаления данных.

## Реальная оплата

Интеграция с ЮMoney сейчас не включена. При её добавлении создание сертификата
нужно вызывать только после подтверждения успешного платежа. Пользовательский
список, карточки и админское погашение при этом менять не потребуется.
