# KOCMOC — Telegram-бот сертификатов

Актуальные исходники второй версии находятся в каталоге
[`telegram_certificate_bot`](telegram_certificate_bot).

Вторая версия работает без реального платёжного провайдера: тестовая кнопка
«Оплатить» выпускает сертификат с UUID, номиналом, комментарием и QR-кодом.
Администраторы из `ADMIN_TELEGRAM_IDS` могут открыть сертификат через QR или
поиск, проверить статус и погасить его в Telegram.

Инструкции по настройке, запуску и тестированию:
[`telegram_certificate_bot/README.md`](telegram_certificate_bot/README.md).

Архивы в корне сохранены как исходные материалы предыдущих передач. Для запуска
бота распаковывать их не нужно.
